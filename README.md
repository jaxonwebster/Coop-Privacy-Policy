# Coop Privacy Policy

Simple static privacy-policy website for Coop.

## GitHub Pages

1. Create a GitHub repository (for example, `coop-privacy`).
2. Upload `index.html` and `styles.css` to the root of the repository.
3. In GitHub, open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public URL. Use that URL as the Privacy Policy URL in App Store Connect.

Before publishing, update the contact email or policy text if your app's data practices change.
